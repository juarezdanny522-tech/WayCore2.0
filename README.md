# WayCore2.0

Proyecto **WayCore + WayHat**: asistente de voz **Karbys** con modelo local
(Qwen2.5-1.5B) corriendo dentro del teléfono, para controlar el dispositivo
de ayuda **WayHat** por Bluetooth.

Todo lo que necesitas (cómo obtener el APK, descargar el modelo, requisitos
del teléfono) está en [wayfix/README.md](wayfix/README.md).
